Horse Race Analyzer v3.1 — Past Performance Viewer

Upload all six files to the root of your existing GitHub Pages repository.
After publishing, refresh the website and re-import the extracted Brisnet .DRF sample, then choose a race and click "Past performances" beside any horse.

Changes:
- Retains up to 10 historical starts per horse from Brisnet single-file PP records.
- Expandable, horizontally scrollable past-performance table for each horse.
- Displays date, track, distance, surface, class, field, call positions, beaten lengths, and Brisnet speed figures when supplied.
- Keeps original experimental ranking formula, based on the first three starts only.
- Updates service worker cache identifier for installed PWA refresh.

Existing saved imports from v3 contained only three starts; re-importing is necessary to see more.
This is an experimental educational tool, not a validated wagering model.
